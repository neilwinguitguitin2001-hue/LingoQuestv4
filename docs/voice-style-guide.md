# Source-only lesson narration

Use only the approved PDF excerpts, unchanged, for lesson narration. The display
text and spoken text must be the same source material. Do not add regional examples,
translations, conversational educational claims, warm-ups, tips or fallback scripts.
See [PDF curriculum policy](PDF_CURRICULUM.md) and the per-module page references.

Voice persona and prosody controls may change how a source excerpt sounds, never
what it teaches. Regenerate cached audio from the new PDF-source segment IDs.
Legacy generated narration caches are removed from this curriculum revision.
